# Signal-Jamming-Detection-System

Real-time DSP-based system for simulating and detecting signal jamming using FFT analysis and SNR monitoring.

Features
FFT Spectrum Analysis
Real-time Signal Visualization
SNR-based Jamming Detection
Audio Alert System
Interactive GUI Dashboard
Multithreading Support
Technologies
Python
NumPy
Matplotlib
CustomTkinter
pygame
Concepts Used
Digital Signal Processing (DSP)
FFT
Signal-to-Noise Ratio (SNR)
Real-Time Systems
